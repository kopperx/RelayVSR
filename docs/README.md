# RelayVSR project page

Static academic project page. No build step is required.

- `index.html`: paper information, abstract, method, results, and inline comparisons.
- `media.js`: 17 sequences and 154 video URLs hosted in [anonyaa/RelayVSR](https://huggingface.co/anonyaa/RelayVSR/tree/main/web-demo-videos).
- Figure PDF/SVG files: original figure PDFs and vector-preserving SVG exports.
- JPEG poster files: video preview frames.

To preview locally, serve this directory using any static HTTP server.
For GitHub Pages, use the `main` branch and the `/docs` folder as the publishing source.

The model download link points to [kopper/RelayVSR](https://huggingface.co/kopper/RelayVSR); demo videos are loaded separately from `anonyaa/RelayVSR`.
